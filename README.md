# Quarterly Earnings Presentation (RevealJS)

This repository contains an interactive, web-based presentation built with **RevealJS** for demonstrating quarterly earnings at a financial institution.

The presentation includes:

- Markdown-based slides  
- Fragment animations  
- Syntax-highlighted code blocks  
- Mathematical equations using MathJax  
- Dynamic SVG data visualizations  
- Custom CSS styling  
- Speaker notes for presenters  
- Hosted on GitHub Pages
